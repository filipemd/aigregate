## KDE Introduces 'Time Travel' for Files

KDE has released KIO Snapshot, a tool that brings Windows-style 'Previous Versions' or macOS 'Time Machine' functionality to Linux. Users can now right-click a file to view and restore past versions saved in Btrfs snapshots, significantly simplifying data recovery for non-technical users.

## Intel Nova Lake Graphics Now Stable on Linux

Intel's next-generation Nova Lake processors' integrated graphics are now officially stable and enabled by default in the Linux Mesa drivers. This ensures that out-of-the-box support for upcoming Intel hardware will be ready before the processors actually launch.

## The Blueprint for X12: Replacing the 40-Year-Old X11

A detailed proposal for 'X12' describes how to fix the fundamental flaws of the X11 protocol, which was designed in the 1980s. While not an active project, the document serves as a critical analysis of X11's legacy bugs and a roadmap for what a modern, secure, and network-transparent windowing system should look like.

- [https://www.x.org/Development/X12/](https://www.x.org/Development/X12/)
