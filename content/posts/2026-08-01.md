## Linux Multi-GPU Performance Boost

Linux is fixing a long-standing performance bottleneck where data was being copied back and forth between integrated and dedicated GPUs. By allowing the compositor to support multiple GPUs, the system can now bypass system memory copies, drastically increasing frame rates for users with external GPUs.

- [https://zamundaaa.github.io/wayland/2026/07/31/fixing-multi-gpu.html](https://zamundaaa.github.io/wayland/2026/07/31/fixing-multi-gpu.html)

## Arch Linux AUR Malware Surge

The Arch Linux User Repository (AUR) has halted package adoptions following a sophisticated malware attack involving over 1,500 malicious packages. Users are urged to remain vigilant as the team works to purge the repository of compromised software.

- [https://www.phoronix.com/news/Arch-Linux-AUR-Adoptions-Halted](https://www.phoronix.com/news/Arch-Linux-AUR-Adoptions-Halted)

## Open-Source Firmware for AMD Ryzen

For the first time, a modern AMD Ryzen desktop motherboard now has open-source firmware. This move reduces reliance on proprietary BIOS/UEFI, providing greater transparency and control for Linux and open-source enthusiasts.

- [https://www.phoronix.com/news/OSS-Firmware-MSI-B850-P-WIFI](https://www.phoronix.com/news/OSS-Firmware-MSI-B850-P-WIFI)

## Intel Nova Lake Graphics Stability

Upcoming Intel Nova Lake processors will have their integrated graphics enabled by default in Linux 7.3. This ensures that the next-generation hardware will be functional out-of-the-box for users starting in early 2027.

- [https://www.phoronix.com/news/Linux-7.3-Intel-NVL-S-Stable](https://www.phoronix.com/news/Linux-7.3-Intel-NVL-S-Stable)

## Servo Browser Engine Progress

The Servo browser engine is rapidly evolving, showing improved compatibility with real-world sites like Lichess and Google Photos. It is also implementing a C API wrapper to make it easier to embed the engine into other applications.

- [https://servo.org/blog/2026/07/31/june-in-servo/](https://servo.org/blog/2026/07/31/june-in-servo/)

## Dotz: Terminal Braille Art Viewer

Dotz is a new terminal-based image and video previewer that uses Braille art to render visuals directly in the command line. It supports a wide range of formats and includes features like zoom, pan, and video seek controls.

- [https://github.com/jarun/dotz](https://github.com/jarun/dotz)
