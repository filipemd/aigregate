## Python's Memory Management Secrets

An exploration of CPython 3.12's memory allocation, detailing how 'pymalloc' handles small objects (≤512 bytes) via arenas and pools to avoid frequent OS requests. The article explains the trade-off: while this speeds up allocation, it prevents the Python process from shrinking in memory usage, as a single live object can keep an entire arena from being returned to the OS.

## Self-Hosted HTTP Tunnels via SSH

A technical guide on creating a secure, self-hosted alternative to ngrok using only OpenSSH and nginx. The system uses remote port forwarding and the ngx_http_secure_link_module to generate hashed, time-limited URLs, allowing developers to expose local services to the internet without relying on third-party commercial services.
