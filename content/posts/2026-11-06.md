## GPU VRAM as Linux Swap

A new beta tool called USM allows Linux users to use idle NVIDIA GPU memory as a high-speed swap space, significantly reducing system slowdowns when RAM is exhausted. Developed largely by AI, the project aims to provide a viable alternative to expensive DRAM upgrades by utilizing existing hardware resources.

- [https://github.com/kha333n/usm](https://github.com/kha333n/usm)

## Linux Kernel 7.4 Memory Fixes

The Linux 7.4 kernel cycle introduces a new Core MM tree to resolve 'nasty long-standing bugs' reported largely by Anthropic. The updates fix critical issues involving data corruption, memory leaks, and deadlocks, improving overall system stability and stability-worthy patches.

- [https://www.phoronix.com/news/Linux-7.4-Core-MM-Nasty-Fixes](https://www.phoronix.com/news/Linux-7.4-Core-MM-Nasty-Fixes)

## UK Nudity Scanning Petition

A UK parliamentary petition is gathering signatures to oppose government mandates requiring tech manufacturers to implement on-device nudity scanning. Critics argue that the mandatory scanning of all user content to detect nudity poses enormous privacy risks and that responsibility should lie with hosting platforms rather than device manufacturers.

- [https://petition.parliament.uk/petitions/776894?](https://petition.parliament.uk/petitions/776894?)

## The 'Devil' in Unix History

A historical deep-dive reveals that in 1980, Bill Joy added a 'daemon' account to Unix with a password field marked by an asterisk, making it impossible to log in, and labeled the account's real name as 'the devil himself'.
