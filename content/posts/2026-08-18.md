## Linux 7.3 to Fix VRAM Overcommit Stutter

Linux 7.3 will introduce code to make gaming more playable when vRAM is maxed out. By improving how the kernel handles memory eviction to system RAM, users with limited GPU memory can maintain playable frame rates even when over-committing by a gigabyte or more, reducing the the severe performance drops typically seen when vRAM is exhausted.

## Intel Boosts Gaming Performance via Buffer Compression

Intel graphics users will see a performance boost of up to 5% in titles like Shadow of the Tomb Raider and Total War through a new update to the Mesa 26.3 driver. The update enables buffer compression for DXVK, allowing Direct3D 8-11 games to run more efficiently on Intel Arc and Panther Lake hardware.

- [https://www.phoronix.com/news/Intel-Buffer-Compression-DXVK](https://www.phoronix.com/news/Intel-Buffer-Compression-DXVK)

## New Tool Prevents RTX 50-Series Connector Meltdown

A new open-source driver allows Linux users with ASUS ROG Astral RTX 5080/5090 cards to monitor individual pins on their power connectors. Because sustained current above 9.5A per pin is known to cause connector melting, the tool provides a critical safety warning system to prevent hardware destruction.

- [https://github.com/ksokolowski/astral-hwmon](https://github.com/ksokolowski/astral-hwmon)
