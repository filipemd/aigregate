## Stop Coupling Go Code to GitHub

Using GitHub URLs as package imports in Go creates a hard coupling to the hosting provider, making migrations to GitLab or other services costly and difficult. The author suggests using custom domains (e.g., go.example.com) and Nginx redirects to maintain control over code location without breaking downstream dependencies.

- [https://iain.rocks/blog/dont-couple-your-go-code-to-github](https://iain.rocks/blog/dont-couple-your-go-code-to-github)

## jBin: Shrinking JSON by 80%

A developer built a custom binary format called jBin that reduces JSON payloads by up to 80% by implementing variable-length integers (varints) and a schema-based approach to eliminate redundant type headers. The project explores the mechanics of LEB128 encoding and the construction of a compiler for a custom schema language.

- [https://hereticpleb.vercel.app/blog/packing-binary-is-fun-actually](https://hereticpleb.vercel.app/blog/packing-binary-is-fun-actually)

## Fixing AWS Lambda Cold Starts with Memory

A .NET AWS Lambda function's cold start time was reduced from 7 seconds to 2.5 seconds simply by increasing memory allocation from 512 MB to 1,769 MB. Because AWS couples CPU power to memory, the higher allocation provided a full vCPU, resolving a CPU-starved initialization process.

- [https://www.lloydatkinson.net/posts/2026/reducing-dotnet-aws-lambda-cold-starts-by-increasing-memory/](https://www.lloydatkinson.net/posts/2026/reducing-dotnet-aws-lambda-cold-starts-by-increasing-memory/)
