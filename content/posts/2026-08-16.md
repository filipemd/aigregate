## Ubuntu's Surprising Shift to Windows

Ubuntu is growing faster on Windows 11 than on native Linux PCs, according to Canonical. This shift is driven by developers—particularly those in AI and machine learning—who are often issued Windows machines by employers but require Linux for their work. Microsoft's continuous improvements to WSL, including GPU passthrough and faster file access, have effectively turned Windows PCs into Linux workstations, removing the the traditional 'OS war' trade-off.

## Koboldcpp Adds Video Generation

Koboldcpp v1.119 introduces support for video generation and Image-to-Video (I2V) using Minimax H3. The update also adds support for Muse Glimmer, Qwen 3.8, and Mistral reasoning budgets, while increasing the limit for image and audio attachments to 64.

- [https://github.com/LostRuins/koboldcpp/releases/tag/v1.119](https://github.com/LostRuins/koboldcpp/releases/tag/v1.119)

## Sib: LLM Conversations as Git Commits

Sib is a Unix LLM client that stores conversations as a Git repository. By treating each user and assistant turn as a commit, it allows users to 'fork' conversations, repeat prompts from specific points in history, and share conversation chains via standard Git remotes.

- [https://github.com/sib-project/sib](https://github.com/sib-project/sib)
