## Ubuntu Completes Rust Transition for Core Utilities

Ubuntu 26.10 will replace the remaining legacy C-based core utilities with Rust-based versions. This move significantly reduces the risk of memory-safety vulnerabilities in the most frequently used system commands.

- [https://www.phoronix.com/news/Ubuntu-Completes-Rust-Coreutils](https://www.phoronix.com/news/Ubuntu-Completes-Rust-Coreutils)

## GNOME 51 'A Coruña' Released

The GNOME 51 update brings offline maps, visual document signatures in Papers, and significant performance boosts to the desktop shell and frame scheduling. It also removes legacy NVIDIA driver interfaces and WEP wireless security.

- [https://release.gnome.org/51/](https://release.gnome.org/51/)
- [https://release.gnome.org/51/developers/](https://release.gnome.org/51/developers/)

## Exploiting Linux Kernel TLB Shootdown Bug

A security researcher successfully turned a known Linux kernel bug into a full exploit by tricking the kernel into recycling a physical memory page as a page table while a CPU still held a stale mapping to it, eventually capturing a flag in Google's kernelCTF.

- [https://blog.himanshuanand.com/2026/09/i-missed-one-tlb-shootdown/](https://blog.himanshuanand.com/2026/09/i-missed-one-tlb-shootdown/)
